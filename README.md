# Portofolio Mao Mao my MBG

Website ini adalah portofolio satu halaman untuk my MBG Mao Mao, seorang ahli ternak lele hias yang berfokus pada perawatan, bisnis, dan estetika.

## Isi Website

Website terdiri dari empat bagian utama:

- **Home**: perkenalan singkat, judul utama, tombol GitHub, dan tombol CV.
- **About**: deskripsi latar belakang dan pengalaman Mao Mao.
- **Skills**: tiga keahlian utama, yaitu manajemen kualitas, bisnis dan pemasaran, serta desain estetika.
- **Contact**: informasi email, LinkedIn, dan Guild Card.

## Teknologi

Website ini dibuat menggunakan:

- HTML5
- Tailwind CSS v4
- JavaScript DOM
